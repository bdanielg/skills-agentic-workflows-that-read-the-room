## Recent updates

### GitHub Copilot

- **Copilot can now interact with desktop apps** via computer use, letting it click, type, and navigate GUIs beyond the editor. (Source: [GitHub Changelog](https://github.blog/changelog/2026-10-01-github-copilot-can-now-interact-with-desktop-apps))
- **Dynamic workflows in Copilot CLI and the Copilot app** make it easier to script multi-step agent tasks from the command line or the app. (Source: [GitHub Changelog](https://github.blog/changelog/2026-10-01-dynamic-workflows-in-copilot-cli-and-the-copilot-app))
- **Copilot code review** now has API support and a new default effort level, useful if you automate review checks. (Source: [GitHub Changelog](https://github.blog/changelog/2026-10-02-copilot-code-review-api-support-and-new-default-effort-level))
- Some older Copilot models are being deprecated — check your configs if you pin a specific model. (Source: [GitHub Changelog](https://github.blog/changelog/2026-10-02-selected-models-in-github-copilot-deprecated))
- **GitHub Copilot in VS Code** shipped its September 2026 release notes, covering editor-side improvements. (Source: [GitHub Changelog](https://github.blog/changelog/2026-10-01-github-copilot-in-vs-code-september-2026-releases))
- Blog deep dive: ["When chat is the wrong UI"](https://github.blog/ai-and-ml/github-copilot/when-chat-is-the-wrong-ui) explores when Copilot should skip the chat box for a more direct interface. (Source: GitHub Blog)
- Blog deep dive: ["How AI code generation works"](https://github.blog/ai-and-ml/generative-ai/how-ai-code-generation-works) is a good primer for readers new to Copilot internals. (Source: GitHub Blog)

### GitHub Actions

- **macOS 14 runner image** is being retired — update workflows pinned to that image before it's removed. (Source: [GitHub Changelog](https://github.blog/changelog/2026-10-01-github-actions-macos-14-runner-image-retirement))
- **Actions retention now covers checks, runs, and statuses**, so cleanup policies apply more broadly across workflow history. (Source: [GitHub Changelog](https://github.blog/changelog/2026-10-01-actions-retention-now-covers-checks-runs-and-statuses))
- **Actions Runner Controller 0.15.0** released, for teams running self-hosted runners on Kubernetes. (Source: [GitHub Changelog](https://github.blog/changelog/2026-10-01-actions-runner-controller-release-0-15-0))
- **Code coverage uploads no longer fail CI for new branches**, fixing a common first-PR friction point. (Source: [GitHub Changelog](https://github.blog/changelog/2026-10-01-code-coverage-uploads-no-longer-fail-ci-for-new-branches))

### GitHub collaboration

- **GitHub async merge API** is now generally available, letting automation merge pull requests without blocking on the call. (Source: [GitHub Changelog](https://github.blog/changelog/2026-10-01-github-async-merge-api-generally-available))
- **New dashboard experience** is now the default for all users — worth a quick look if your homepage layout changed. (Source: [GitHub Changelog](https://github.blog/changelog/2026-10-01-new-dashboard-experience-now-the-default))
- **Accessibility statements** are now highlighted on the repository overview page. (Source: [GitHub Changelog](https://github.blog/changelog/2026-10-01-accessibility-statements-highlighted-on-repository-overview))
- **Scheduled code scanning** now skips inactive repositories, saving unnecessary runs. (Source: [GitHub Changelog](https://github.blog/changelog/2026-10-01-scheduled-code-scanning-skips-inactive-repositories))
- Blog read: ["Highlights from Git 2.56"](https://github.blog/open-source/git/highlights-from-git-2-56) rounds up the newest Git features worth knowing. (Source: GitHub Blog)
